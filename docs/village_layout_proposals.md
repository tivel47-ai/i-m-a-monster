# Предварительные варианты планировки первой деревни

**Статус:** три предварительных предложения, не утверждённые как финальная планировка  
**Дата:** 30 октября 2026 года  
**Связанные документы:** [GDD](game_design.md), [TDD](technical_design.md), [Проектирование карты](map_design.md)

## 1. Важные ограничения

Эти варианты не являются утверждённой схемой карты и не должны восприниматься как финальная планировка деревни. Они разработаны только для обсуждения и проверки логики пространства, маршрутов, укрытий, проходов и зон тревоги. Размер карты, точные размеры улиц, точная плотность застройки, масштаб графики и параметры навигации не утверждаются.

Принятые требования проекта:

- 2D pixel art, вид сверху без изометрии;
- тёмное готическое средневековое фэнтези;
- одна небольшая деревня для MVP;
- игрок видит деревню сразу, без отдельного режима разведки;
- жители перемещаются между домами, рабочими местами и общественными точками;
- дома используются для укрытия жителей;
- здания и стены блокируют прямую видимость;
- колокол/сигнал нужен для распространения тревоги;
- маршруты, улицы и проходы должны быть проверяемыми для одиночных зомби и групп;
- визуальная геометрия, физические коллизии и навигация должны согласовываться.

## 2. Вариант 1 — компактная деревня вокруг центральной площади

### Общая структура

Этот вариант наиболее безопасен для MVP: деревня компактна, зрительно читаема и легко проверяется на навигацию. В центре располагается общественное пространство, вокруг которого формируется основная застройка. Дома образуют замкнутый узел с несколькими подходами, а внешняя зона отводится под поля/огороды и природную окраину.

```text
+------------------------------------------------------+
|   Лесная окраина                                     |
|      ~~~   ~~~      ~~~                              |
|                                                      |
|   [Поля/огороды]   [Поля/огороды]                    |
|       ~   ~      ~   ~                               |
|     +----------------------------+                 |
|     |  Дом  Дом   Дом            |                 |
|     |  Дом   Дом   Дом           |                 |
|     |       [Площадь]            |                 |
|     |   КОЛОДЕЦ / Общественный   |                 |
|     |     центр / рынок          |                 |
|     |  Дом   Дом   Дом           |                 |
|     +----------------------------+                 |
|     /      Улица / проход      \                    |
|  [Пост стражи]        [Церковь/часовня]             |
|      \       /                                        |
|       [Кузница/мастерские]                           |
|                                                      |
+------------------------------------------------------+
```

### Состав и размещение

- Жилые дома: компактная группа вокруг площади, небольшие промежутки для проходов.
- Общественные зоны: центральная площадь, колодец, небольшая рыночная зона или площадь перед церковью.
- Хозяйственная зона: на периферии, сбоку или за жилой группой, чтобы не мешать центральному движению.
- Церковь/часовня: отдельный компактный объект у одной из границ площади или рядом с главной улицей.
- Колокол: желательно возле площади, центральной улицы или рядом с постом стражи.
- Пост стражи: у главного входа или на одной стороне площади, в точке, где удобно перекрывать дорогу.
- Лесная окраина: внешний край карты, за полями или за жилой группой, создающий естественную границу.

### Основные маршруты

- Главная улица ведёт от входа к площади.
- Внутренние проходы соединяют жильё, колодец, церковь и хозяйственные зоны.
- Задний проход между домами создаёт резервный маршрут для обхода.

### Узкие проходы и открытые участки

- Есть один или два узких северо-восточных/западных прохода между домами.
- Центр площади остаётся открытым, что даёт простор для боёв, но требует контроля со стороны стражи.

### Потенциальные точки столкновения

- У входа на площадь.
- Уколодца и вокруг него.
- У ворот/главной улицы, где зомби могут быть встречены стражей.
- В узком проходе между домами, если стража отрезает путь.

### Преимущества

- Лёгкая читаемость карты.
- Быстрый старт и простая навигация.
- Хорошая работа с центральной точкой тревоги.
- Удобно проверять движение группы и обход зданий.

### Недостатки

- Несколько маршрутов могут оказаться слишком прямыми и легко перекрываться в узких точках.
- Компактность повышает риск плотных столкновений.
- Если площадь слишком открытая, может возникнуть слишком быстрый поток агро и скопление зомби.

### Сложность реализации и проверки навигации

- Низкая-to-medium: компактная геометрия проще для `NavigationRegion2D` и коллизий.
- При необходимости легко проверять, что базовые проходы остаются пригодными для группы.

## 3. Вариант 2 — деревня вдоль главной дороги

### Общая структура

Деревня вытянута вдоль одной главной дороги, которая ведёт от лесной окраины к общественной части. Жилые дома располагаются по обе стороны дороги, а хозяйственные зоны и общественные точки располагаются в промежутках или у концов полосы застройки.

```text
+-----------------------------------------------------------+
| Лесная окраина                                            |
|    ~~~  ~~~                                               |
|          |                                                |
| [Поля/огороды]----[Кузница/мастерские]---[Площадь]---[Церковь]|
|             |       Дом  Дом   Дом      |        Фермы/дома |
|             |       Дом  Дом   Дом      |                    |
| [Пост стражи]----Главная улица----[Колодец]---------------|
|             |       Дом  Дом   Дом      |                   |
|             \       Дом  Дом   Дом      /                   |
|              \_____[Хозяйственный двор]_____/               |
+-----------------------------------------------------------+
```

### Состав и размещение

- Основная ось: главная улица от окраины до площади.
- Жилые дома: по обе стороны оси, с основными входами к улице.
- Хозяйственные зоны: в конце улицы или за домами, давая пространство для огородов и мастерских.
- Церковь/часовня: либо у площади, либо в конце дороги, как фокусный объект.
- Колокол: лучше у центральной площади или рядом с постом стражи.
- Пост стражи: у входа в деревню или возле главного перекрёстка.
- Лесная окраина: один край, соединённый с основной дорогой.

### Основные маршруты

- Основной маршрут: по дороге между окраиной, площадью и хозяйственными зонами.
- Дополнительные маршруты: между домами, через небольшие боковые проходы и задние дворы.
- Основной поток жителей и зомби идёт по оси, а боковые проходы служат обходами.

### Узкие проходы и открытые участки

- Есть длинная центральная линия движения и несколько боковых узких проходов между домами.
- Открытых участков меньше, чем в компактной схеме, но меньше и свободных обходных путей.

### Потенциальные точки столкновения

- У входной части, где всё движение концентрируется на одной дороге.
- В районе площади и колодца.
- Вблизи поста стражи, если он блокирует дорогу.
- На узких проходах между домами, если игрок использует обход.

### Преимущества

- Сильная визуальная и игровая логика: одна главная улица и чёткая ось сюжета.
- Удобно показать, как тревога распространяется через одну центральную артерию.
- Подходит для простой истории появления угрозы и обороны.

### Недостатки

- Слишком выраженная главная дорога может ограничить разнообразие маршрутов.
- Если дорога перекрывается, деревня теряет значительную часть мобильности.
- Со временем может выглядеть слишком линейной и менее “живой”.

### Сложность реализации и проверки навигации

- Medium: главное движение по одной оси, но важно безопасно предусмотреть обходы и резервные маршруты.
- Необходимо следить, чтобы узкая ось не превращалась в единственную точку зависимости.

## 4. Вариант 3 — деревня с несколькими кварталами и улицами

### Общая структура

Это более сложный и более “поселенческий” вариант: деревня разделена на несколько кварталов, соединённых улицами и маленькими проходами. Он лучше передаёт ощущение живой деревни, но требует более аккуратного проектирования навигации, чтобы маршруты не превращались в тупики.

```text
+-------------------------------------------------------+
| Лесная окраина     |   [Поля/огороды]    |  Лесная окраина |
|        ~~~         |      ~~~             |        ~~~   |
|                    |                      |              |
|  Дом Дом     [Площадь]     Дом Дом                    |
|  Дом Дом  [Колодец/рынок]  Дом Дом                    |
|      |         |             |                        |
|  [Церковь]   [Пост стражи] [Кузница]                  |
|      |        / \          |                         |
|  Дом Дом---Улица---Дом Дом                            |
|      |        \ /          |                         |
|   [Хозяйственный двор]    [Дом/мастерская]             |
|   ~~~~     ~~~~       ~~~~                             |
+-------------------------------------------------------+
```

### Состав и размещение

- Несколько отдельных жилых кварталов, соединённых главной улицей и второстепенными проходами.
- Центральная площадь в одном из узлов, но не обязательно в геометрическом центре дерева.
- Хозяйственная зона — в одном из внешних краёв или между кварталами.
- Церковь/часовня — в более тихом углу, отделённом от оживлённой улицы.
- Колокол: у площади или в одном из общих узлов, которые легко заметить во время тревоги.
- Пост стражи: на входе, у перекрёстка или в районе центральной улицы.
- Лесная окраина: внешний периметр, естественная граница между полями и деревней.

### Основные маршруты

- Главная улица соединяет вход, площадь, пост стражи и церковь.
- Второстепенные улицы обслуживают разные кварталы.
- Дополнительные проходы между домами обеспечивают обходы и возможность изолировать один квартал.

### Узкие проходы и открытые участки

- Несколько узких проходов между домами и жилыми кварталами.
- Есть хотя бы один открытый путь к площади, чтобы не застревать в тупике.
- Для движения группы важно, чтобы не было только одной “магистрали”.

### Потенциальные точки столкновения

- Центральная улица.
- Перекрёсток между кварталами.
- Главные входы в жилые участки.
- Места возле транспорта/складов и в районе хозяйственной зоны.

### Преимущества

- Самый “живой” и разнообразный внешний вид деревни.
- Хорошо подходит для ощущения поселения и нескольких логических районов.
- Задает больше вариантов обхода и тактической гибкости.

### Недостатки

- Сложнее проектировать навигацию и проверять проходимость групп.
- Лёгко получить избыточное количество узких проходов и бесполезных мёртвых зон.
- Может создавать неоднозначные маршруты и локальные пробки в бою.

### Сложность реализации и проверки навигации

- High: требуется тщательная проверка путей, проходов и мест с узкими коридорами.
- Перед реализацией нужна отдельная навигационная проверка для групп и защитников.

## 5. Сравнение вариантов

| Критерий | Вариант 1: компактная площадь | Вариант 2: главная дорога | Вариант 3: кварталы |
|---|---|---|---|
| Общая читаемость | Высокая | Высокая | Средняя |
| Гибкость маршрутов | Средняя | Средняя | Высокая |
| Риск узких тупиков | Низкий-to-medium | Medium | Высокий |
| Подходит для MVP | Очень хорошо | Хорошо | Условно |
| Удобство проверки навигации | Высокое | Среднее | Низкое-to-medium |
| Открытые пространства | Хорошо | Средне | Хорошо |
| Плотность столкновений | Средняя | Высокая | Средняя |
| Эстетика деревенской жизни | Хорошая | Хорошая | Очень хорошая |
| Сложность реализации | Низкая | Средняя | Высокая |

## 6. Предпочтительный вариант

Я рекомендую вариант 1: компактная деревня вокруг центральной площади.

Причины:

- он лучше всего отвечает критериям MVP: простая, читаемая и проверяемая карта;
- он даёт достаточно открытого пространства для сцены и позволяет устроить центральную тревогу и оборону без чрезмерной сложности;
- его проще проверять на навигацию, коллизии и обход препятствий для одиночных зомби и групп;
- он помогает быстро подтвердить базовый игровой цикл: появление угрозы, переход тревоги, перемещение, укрытие жителей и организация обороны;
- он лучше удерживает баланс между визуальной выразительностью и технической надёжностью.

Для первой миссии деревня должна ощущаться как живой небольшой населённый пункт, но при этом вся инфраструктура должна оставаться достаточно понятной для механик и проверяемой для разработки карты.

## 7. Что должен утвердить автор игры до создания карты

Перед созданием карты необходимо согласовать:

1. Обязательный состав первой деревни: какие объекты обязательно нужны в MVP.
2. Нужна ли центральная площадь как обязательный элемент первого уровня.
3. Должна ли деревня иметь одну главную улицу или несколько связей между зонами.
4. Требуется ли церковь/часовня как обязательный объект или она может быть условным декоративным элементом в первых миссиях.
5. Должен ли колокол быть значимым визуальным объектом или достаточно сигнального элемента, не явно выделенного на карте.
6. Нужно ли у деревни явно выделять хозяйственную зону и пограничную природную окраину в первую миссию.
7. Какой тип шаблона движения лучше подходит: компактный кластер, линейная дорога или мульти-квартальный узел.
8. Нужен ли дополнительный запас маршрутов на случай одной заблокированной улицы.
9. Какая степень сложности навигации допустима в MVP.
10. Какую роль должна играть деревня в общей атмосфере: узкая и плотная, или более просторная и “живописная”.

## 8. Итог

Все три варианта остаются предварительными и не должны связывать дальнейшую разработку картой без согласования. Вариант 1 выглядит лучшим стартовым кандидатом для MVP, потому что он проще структурировать, проще проверять и лучше поддерживает базовый игровой цикл. Остальные варианты полезны как альтернативы, если автор игры хочет более линейную или более разрозненную деревню.

Этот документ не утверждает финальную планировку. Он служит основой для дальнейшего обсуждения и выбора одного варианта перед созданием карты.
